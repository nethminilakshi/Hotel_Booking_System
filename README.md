# Hotel Booking System-

# Description :
    The Hotel Booking System is a full-stack web application built using Spring Boot for the backend and HTML, CSS, JavaScript, and jQuery for the frontend, with MySQL as the database.
    booking system includes features like role-based access control using JWT authentication.Admins can manage hotels and rooms with image uploading. Users can register, log in, and make bookings by selecting 
    a hotel, room type, date, and time slot (Day/Night), with the system checking real-time room availability. After staying, users can leave reviews with ratings and comments, which are dynamically displayed on the frontend.
    The system includes dynamic content loading (such as hotels and room types), secured endpoints, image preview functionality for room updates, and a responsive, interactive UI.
    All booking and review operations rely on proper authentication, ensuring that users must be registered and logged in before proceeding.
